# Stock_Price_Analysis
Power BI Stock Price Analysis Dashboard
Project Type: Business Analytics — Power BI
Project Overview
This project presents an interactive stock price analysis dashboard built using Microsoft Power BI.
Key Features

Historical stock closing price analysis
Trading volume analysis
Stock selection using slicers
Comparison of selected stocks with the S&P 500

Tools Used

Microsoft Power BI
Power Query
DAX
Stock market dataset
